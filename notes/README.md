# 🧠 Notas Acadêmicas e PKM (`notes/`)

Espaço dedicado à síntese de leituras, fichamentos críticos e notas conceituais atômicas (metodologia Zettelkasten / Second Brain).

## 📁 Organização

- `literature/`: Fichamentos diretos de livros, artigos do Lake (`resources/_lake/`) e palestras transcritas.
- `concepts/`: Ideias consolidadas, teoremas, comparações de abordagens metodológicas e modelos teóricos.

## ✍️ Boas Práticas

1. **Atomicidade:** Cada nota deve tratar de uma ideia ou conceito principal.
2. **Conexões:** Use links relativos no padrão Markdown para conectar ideias (`[Conceito X](../concepts/conceito_x.md)`).
3. **Rastreabilidade:** Sempre cite a chave da obra em `references/master.bib` (ex: `[@gil2022projetos, p. 45]`).
